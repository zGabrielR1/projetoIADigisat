# Project preferences

For front end work, read `docs/frontend-design.md` before making visual changes.

- Preserve the approved Pulse-inspired direction: deep navy surfaces, blue-to-indigo accents, subtle glow, fine borders, white headings, and locally bundled Inter.
- The user approved the refined dashboard layout and typography, but rejected the earlier lime palette. Avoid returning to lime or replacing the layout with a superficial theme overlay.
- Use the Taste design skill from `Leonxlnx/taste-skill` when it can improve design work. Follow the user's approved references and preferences over conflicting skill defaults.
- Validate visual changes in the browser on desktop and mobile, including dark and light modes. Keep assets local and preserve the suite's offline operation.
- Light mode follows the newer `LightModeReference.webp`: white surfaces, a neutral gray canvas, dark ink and deep teal actions/navigation. Load `static/light.css` last; Pulse navy/blue remains the dark-mode direction. The newer light reference supersedes older instructions about a blue light palette.
